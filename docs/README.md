## 🚀 Quick Start | 快速开始

### 中文用户

2. 运行 `python configure.py` 进行配置
3. 查看 [Subagent 使用指南](zh/SUBAGENT_GUIDE.md) 使用 AI 功能

### English Users
1. Read [Installation Guide](en/INSTALLATION.md)
2. Run `python configure.py` for setup
